How to Redeem Meteor Rank

Follow these simple steps in-game to claim your Meteor rank:

  1. Join the server at meteorsmp.abrdns.com
  2. Buy the Meteor rank above to get your unique code (e.g. METEOR-5949)
  3. Type the command in-game: /redeem METEOR-5949
  4. Type the command in-game: /pay server 5b

Your rank and perks will be unlocked instantly!
